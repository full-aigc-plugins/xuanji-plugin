# 玄机 · 塔罗（娱乐向）

## 流程（三步）

Step 1 — 问与阵：确认用户所问之事（一个问题），按问题复杂度选阵型（对照 [references/spreads.md](references/spreads.md)：快问 one-card，常规 three-card，多面 five-card，全面 celtic-cross）。
Step 2 — 抽牌（必须走脚本）：
   ```bash
   python3 scripts/draw.py --spread three-card --question "最近的事业方向" --seed 20260922
   ```
   - `--seed` 用于复现；用户未要求复现时省略。
   - 抽牌结果以脚本 JSON 为准，禁止"心里先有答案再配牌"。
Step 3 — 解读：每张牌 = 位置义 × 牌义 × 正逆位（[references/cards.md](references/cards.md)），先逐张解读，再合成整体叙事；结尾回答用户所问。

## 口径

- 逆位 = 同一主题的"卡住/过度/内化"，不是简单反义。
- 骤变牌（高塔/死神）出现在走向位时，解读为"旧阶段必要收束"，语气中性建设性。
- 引用塔罗相关"古籍"无出处可循时，直接以自己的话概括，不得伪托典籍。

## 边界

- 输出末尾附免责声明：本结果为传统术数的娱乐化演绎，仅供娱乐，不构成任何医疗、法律、投资或其他专业建议；如有现实需求，请咨询相关专业人士。
- 医疗/法律/投资类提问拒绝以牌面作答，建议咨询专业人士。

## Gotchas

1. **别先入为主**：先跑抽牌脚本拿结果，再解读；先写结论再配牌是本技能最重的翻车点。
2. **逆位不是反义**：把逆位读成"卡住/过度/内化"，不要生造反义。
3. **骤变牌不恐吓**：高塔/死神落在走向位时，读成"旧阶段必要收束"，语气中性。
4. **一问一阵**：同 seed 可复现；用户要"再抽一次"就换 seed，不要在同一结果上反复加戏。

## When to Use / Boundary

- 什么时候用：用户带着一个具体问题想抽牌，或提到塔罗/牌阵/占卜卡。
- 不适用：用户想要"确定的事实答案"（塔罗给的是视角不是事实）；医疗、法律、投资决策咨询（越界拒答）。

## Security

本技能不收集、不上传、不发送任何用户数据；无密钥、无凭据、无外部网络请求；排盘与校验全部由本地脚本完成。
