# 塔罗牌阵（原创整理）

抽牌张数由 `scripts/draw.py --spread` 决定；本表给出每个位置的含义。解读 = 位置义 × 牌义（[cards.md](cards.md)）× 正逆位。

| 阵型 | 张数 | 位置语义（按 position 顺序） |
|---|---|---|
| one-card | 1 | 1 = 当下之事的核心答案 |
| three-card | 3 | 1 = 过去/起因，2 = 现在/现状，3 = 走向/结果 |
| five-card | 5 | 1 = 现状，2 = 阻碍，3 = 可借之力，4 = 建议动作，5 = 可能结果 |
| celtic-cross | 10 | 1 = 现状核心，2 = 横跨的挑战，3 = 根基/潜意识，4 = 近来的过去，5 = 显意识/目标，6 = 近未来，7 = 自我状态，8 = 环境/他人，9 = 希望与恐惧，10 = 最终走向 |

## 使用约束

- 一次问测一个牌阵；同 seed 可复现，用户要求"再抽一次"即换新 seed（或省略 --seed）。
- 逆位不是"反义"，是"卡住/过度/内化"的同一主题变奏。
- 最终走向若为高塔/死神等骤变牌，话术保持中性建设性，不做恐吓性断言。
