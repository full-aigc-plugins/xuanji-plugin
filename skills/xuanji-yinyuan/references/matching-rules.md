# 姻缘测算规则（原创整理）

> 原创整理（玄机插件）。仅参考无 license 上游"多模式菜单 + 求签脚本"的结构模式，文案与规则全部自写。

## 六模式菜单（进入技能先展示，用户选号）

| 模式 | 需要的信息 | 走的脚本 |
|---|---|---|
| 1 八字合婚 | 双方阳历生日+时辰+性别 | hand off to the **`xuanji-bazi`** skill. Install: `npx skills add full-aigc-plugins/xuanji-plugin --skill xuanji-bazi`（排盘后回到本技能做配对解读） |
| 2 生肖配对 | 双方生肖或出生年份 | 本技能（生肖规则表，见下） |
| 3 紫微夫妻宫 | 一方生日+时辰+性别 | hand off to the **`xuanji-ziwei`** skill. Install: `npx skills add full-aigc-plugins/xuanji-plugin --skill xuanji-ziwei` |
| 4 求签问姻缘 | 想问的问题 | `scripts/qiu_qian.py`（24 支原创示意签） |
| 5 桃花运势 | 生肖 + 当前感情状态 | 本技能（桃花规则表，见下） |
| 6 八字速配 | 双方阳历生日（无时辰亦可） | 本技能（干支纪年速配，见下） |

## 生肖规则表（自写口径）

- 六合（六合贵人，+2）：子丑、寅亥、卯戌、辰酉、巳申、午未。
- 三合（同气连枝，+2）：申子辰、亥卯未、寅午戌、巳酉丑。
- 相冲（观念易冲突，-2）：子午、丑未、寅申、卯酉、辰戌、巳亥。
- 相刑（细节易摩擦，-1）：子卯、寅巳申、丑未戌、辰午酉亥自刑。
- 计分仅供参考：>0 合拍，0 平淡经营，<0 需要多沟通。**不做"生肖不合就分手"式结论。**

## 干支纪年速配（模式 6，无时辰降级口径）

- 年支按立春分界（与 xuanji-bazi 年柱口径一致；仅知出生年不知日期时按公历年近似，并注明此近似）。
- 只比年支六合/三合/冲刑，精度有限 → 结论统一加"年支速配仅为粗筛，时辰齐全的八字合婚更细"。

## 桃花规则表（自写口径）

按年支三合组定桃花位：申子辰见酉、亥卯未见子、寅午戌见卯、巳酉丑见午。
- 当前年份地支 = 本人桃花位 → "走动桃花"（社交活跃期，单身利脱单、有伴防暧昧越界）。
- 本人日支/年支 = 桃花位 → "坐命桃花"（天然人缘好）。
- 娱乐口径：只描述氛围趋势，不给"本月必脱单"承诺。

## 解读红线

- 全部模式输出末尾附免责声明（口径见 harness）。
- 不做"你们不合适"式劝分结论；只描述倾向与沟通建议。
- 涉及第三者、婚姻危机等敏感问题：以中立话术引导理性沟通，不做道德审判。
