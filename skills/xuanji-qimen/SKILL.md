# 玄机 · 奇门遁甲（娱乐向）

## 流程（四步）

Step 1 — 问事：确认所问之事（一事一局）。
Step 2 — 定局：阴阳遁与局数由用户/其流派口径给定（MVP 不做时家定局，如实说明）。
Step 3 — 报盘 + 校验（必须走脚本）：
   ```bash
   python3 scripts/verify_pan.py --mode yang --ju 3 \
     --dipan '{"1":"戊","2":"己","3":"庚","4":"辛","5":"壬","6":"癸","7":"丁","8":"丙","9":"乙"}' \
     --bamen 休,生,伤,杜,景,死,惊,开 --jiuxing 天蓬,天任,天冲,天辅,天英,天芮,天柱,天心,天禽
   ```
   退出码非 0 = 盘不合法：**禁止基于它解读**，重排后复检。校验口径见 [references/ruleset.md](references/ruleset.md)。
Step 4 — 解读：按 ruleset 第 6 节用神映射做娱乐化解读，给趋吉避凶方向，不出恐吓断语。

## 边界

- 输出末尾附免责声明（口径见 harness）：本结果为传统术数的娱乐化演绎，仅供娱乐，不构成任何医疗、法律、投资或其他专业建议；如有现实需求，请咨询相关专业人士。
- 医疗/法律/投资类提问拒绝起局作答，建议咨询专业人士。

## Gotchas

1. **校验不过就停**：verify_pan.py 退出码非 0 = 盘不合法，禁止基于它解读，这是硬门。
2. **定局口径要说清**：MVP 不做时家定局，阴阳遁与局数来自用户/其流派，务必如实说明。
3. **用神别乱套**：事业看值符/开门宫、婚恋看六合、财物看生门/戊，映射错了整段解读全歪。
4. **别改盘就说法**：解释服从盘面，不得反过来改宫位迁就话术。

## When to Use / Boundary

- 什么时候用：用户就一件具体的事问吉凶、方位、时机，或提到奇门/起局/问测。
- 不适用：泛泛问"我今年运气如何"（奇门是一事一局）；医疗、法律、投资决策咨询（越界拒答）。

## Security

本技能不收集、不上传、不发送任何用户数据；无密钥、无凭据、无外部网络请求；排盘与校验全部由本地脚本完成。
