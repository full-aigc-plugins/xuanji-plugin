# 玄机 · 阳宅风水（娱乐向）

## 流程（三步）

Step 1 — 收集：入住年代或当前元运（2024 年起为九运，可直接采用）；用户住宅各功能分区（卧室/书房/客厅/玄关）大致方位（口述即可，如"主卧在北边"）。缺朝向时只做运盘通用建议，不猜坐向。
Step 2 — 取盘（必须走脚本）：
   ```bash
   python3 scripts/fei_xing.py --yun 9            # 计算九运运盘
   python3 fei_xing.py --yun 9 --verify '{"5":9,...}'  # 校验模型报盘
   ```
   飞泊路径与九星口径见 [references/feixing.md](references/feixing.md)；校验退出码非 0 = 禁止解读。
Step 3 — 解读：把运盘九星对到用户口述的功能分区，给**物理整理级别**的建议（整洁、采光、收纳、绿植、动线）；五黄/二黑等"凶位"话术 = "安静整洁、不堆杂物"，不做恐吓。

## 红线（本技能特别加强）

- **不给**任何"化煞用品/法器/摆阵/挂符"购买或布置指引——这是硬红线，不是风格偏好。
- 不以风水为由评价"这房子不能住人/必生病"类断言。
- 输出末尾附免责声明：本结果为传统术数的娱乐化演绎，仅供娱乐，不构成任何医疗、法律、投资或其他专业建议；如有现实需求，请咨询相关专业人士。

## Gotchas

1. **别猜坐向**：用户没给坐向就只做运盘通用建议，缺数据脑补坐向是最大翻车点。
2. **凶位不恐吓**：五黄/二黑只说"安静整洁、不堆杂物"，禁止"必生病"式断言。
3. **功能分区是用户口述**：哪间卧室在北是用户说的，脚本只管飞星，别替用户定位房间。
4. **只给物理整理建议**：整洁/采光/收纳/绿植级别；任何购物指引都是红线。

## When to Use / Boundary

- 什么时候用：用户想按玄空飞星看住宅布局、搬新家、或提到风水/旺位/飞星盘。
- 不适用：要求"化煞法器/摆阵/挂符"购买指引（硬红线，拒绝）；判断"这房子能不能住人"（越界拒答）。

## Security

本技能不收集、不上传、不发送任何用户数据；无密钥、无凭据、无外部网络请求；抽取与校验全部由本地脚本完成。
