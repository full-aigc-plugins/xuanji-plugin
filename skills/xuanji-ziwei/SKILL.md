# 玄机 · 紫微斗数（娱乐向）

## 流程（三步）

Step 1 — 收集：阳历生日 + 时辰 + 性别（缺时辰时如实说明：命宫不定，MVP 拒排，请用户补时辰）。
Step 2 — 报盘 + 校验（必须走脚本）：
   ```bash
   python3 scripts/verify_chart.py \
     --palaces '{"命宫":["紫微","天府"],"夫妻宫":["贪狼"],"官禄":["天相"]}' \
     --sihua '{"化禄":"武曲","化权":"太阳","化科":"天梁","化忌":"廉贞"}'
   ```
   十二宫须齐全（别名仆役/事业自动归一）；退出码非 0 = 盘不合法，禁止解读，重排复检。星曜口径见 [references/stars.md](references/stars.md)。
Step 3 — 解读：命宫主星定基调 → 三方四正补格局 → 四化点增减项。只解释校验通过的盘，盘面数字不得改。

## 边界

- 安星公式不在 MVP 校验范围：模型报盘即视为"按所学流派安星的结果"，脚本只保证结构合法，如实告知用户此口径。
- 输出末尾附免责声明（口径见 harness）：本结果为传统术数的娱乐化演绎，仅供娱乐，不构成任何医疗、法律、投资或其他专业建议；如有现实需求，请咨询相关专业人士。
- 医疗/法律/投资类提问拒绝以命盘作答，建议咨询专业人士。

## Gotchas

1. **缺时辰不硬排**：命宫依赖时辰，用户给不出就请补，别猜一个时辰排着玩。
2. **主星重宫即废盘**：同一主星出现在两宫 = 安星错误，校验会 FAIL，重排别辩解。
3. **四化只挂主星**：化禄/权/科/忌的值必须是十四主星，挂辅星直接 FAIL。
4. **别名已归一**：仆役→交友、事业→官禄由脚本自动归一，报盘用原名也不报错，但解读时用统一名。

## When to Use / Boundary

- 什么时候用：用户想看本命盘性格格局、宫位话题，或提到紫微/命宫/四化。
- 不适用：缺出生时辰（命宫不定，请用户补齐）；医疗、法律、投资决策咨询（越界拒答）。

## Security

本技能不收集、不上传、不发送任何用户数据；无密钥、无凭据、无外部网络请求；排盘与校验全部由本地脚本完成。
