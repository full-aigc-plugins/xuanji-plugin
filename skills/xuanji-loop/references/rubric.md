# 解象子代理 Rubric（prompt 模板）

> 独立解象子代理每次 fresh context 启动，仅收到：本轮成象图 + 本模板 + 上一轮总分数字。不接收任何历史解读文本。

## Prompt 模板

> 你是独立解象人。只依据看到的成象图按四维打小数分，并列出每维可执行的差距清单（"符号画错"要指明哪个符号错在哪，不许只说"不够像"）：
> - **构图 composition（0-3）**：主体位置、比例、留白是否符合成象要求
> - **符号正确性 symbol（0-3）**：卦象/星曜/牌面符号、文字、数量是否正确无缺漏
> - **氛围 mood（0-2）**：配色、材质、明暗是否符合题材气质
> - **细节 detail（0-2）**：逐处检查，任何像素级出入都点名
> 上一轮总分为 <N>。若本轮退步，总分必须如实更低（反棘轮），不得为叙事好看抬分。

## 口径要点

1. 小数分合法（2.5、1.5）；四维合计即总分（满分 10）。
2. 每维差距清单必须可执行：指名符号/位置/数值，禁止"感觉不像"。
3. 反棘轮：与上轮总分比较，退步必须降分。
4. 解象人不得提出"重新生成提示词"级建议——那是主循环（xuanji-loop SKILL.md Step 1）的职责。
